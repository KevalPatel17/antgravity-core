# Changelog

All notable changes to the **Antigravity Core** extension will be documented in this file.

## [1.0.0] - 2026-08-31

### Added
- 🎉 Initial release
- ⚡ Auto Switch feature — automatically switches models and accounts when credits run low
- 📊 Sidebar dashboard with dark professional theme
- 🔄 Smart decision tree: model switch → account switch → warning
- 📈 Status bar with color-coded credit display
- ⚙️ Configurable settings: threshold, interval, model priority
- 📋 Switch history log with timeline view
- 📦 Import/Export account sessions as JSON
- 🎨 Draggable model priority reordering
- 🔔 Notification system for switch events
